Automated pet feeder project 
Overview :--
This project is regarding a automatic pet feeding food dispensing system which is designed for a pet shelter to dispense food at particular times of 
the day, this is a low cost feeder which is meant to do :- 
a) Dispense food on time. 
b) Makes sure that every animal has eaten food. 
c) Makes an alert if there is an error in the system.
To make this project I used the steps that were taught in the class nad tutorial in week 1 and week 2.
